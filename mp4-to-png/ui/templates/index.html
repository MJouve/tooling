MP4 → SpriteSheet (UI)

Charge un MP4, ajuste les paramètres, puis génère une spritesheet PNG + le JSON adjacent (même nom en .json) via mp4-to-sprite.py.

Aperçu vidéo
Glisse-dépose un MP4 ici, ou clique “Choisir un MP4”.
Crop: clique “Capturer frame” puis dessine un rectangle.
Astuce: tu peux lire la vidéo ici pour repérer les valeurs start / end.
Paramètres
Config: sauvegarder/charger un JSON de paramètres.
